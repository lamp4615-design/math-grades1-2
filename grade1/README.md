# 一年級數學樂園

一年級數學學習扶助的線上練習遊戲。

## 遊戲

- **數字森林闖關**（`number-forest.html`）— 18 關數學大冒險，涵蓋數與位值、計算、量與形、時間與生活四大類，全文搭配注音。
- **數感快手**（`number-sense.html`）— 專門訓練數感、擺脫手指頭數數的限時特訓遊戲。「閃數快認」練習一眼看出點數，
  「湊十配對」練習補數反應，兩種混合的「綜合特訓」隨等級提升逐漸加快加難。有等級／經驗值系統，也有班級排行榜可以互相較勁。
- **時鐘操作室**（`clock-lab.html`）— 可以用手指或滑鼠轉動長針的互動時鐘，短針會跟著連動，讓孩子親手看到「長針走一圈，短針走一格」。
  四種模式：「自由撥撥看」（老師可投影大時鐘上課示範）、「撥出時刻」（依題目撥出整點、半點）、
  「時間經過」（親手把長針轉一圈、兩圈再作答）、「讀讀看」（選項含常見錯誤，答錯會說明錯在哪裡）。
  全文搭配注音，可按 🔊 唸題目；登入身分與成績紀錄和數字森林共用，成績寫入「作答紀錄」工作表（關卡ID 為 `clockLab-…`）。

兩個遊戲共用同一套班級/姓名登入與教師後台，設定一次即可。

## 檔案說明

- `index.html` — 進入頁，可以選擇要玩哪一個遊戲。
- `number-forest.html`、`number-sense.html`、`clock-lab.html` — 遊戲本體，開啟即可玩（不需要伺服器，也可以直接放到任何靜態網頁空間）。
- `Code.gs` — 教師後台用的 Google Apps Script 程式碼。部署成 Web App 後，把網址貼到任一遊戲右上角的齒輪設定，
  就能讀取班級名單並自動記錄每個孩子的作答結果、數感特訓成績到 Google 試算表。詳細部署步驟寫在檔案開頭的註解裡。

## 快速開始

1. 直接打開 `index.html`（或個別的遊戲頁面）就能玩，不需要任何設定。
2. 如果要讓老師端記錄成績、看到班級排行榜，照 `Code.gs` 開頭的步驟部署 Google Apps Script，
   再把網址貼到任一遊戲的齒輪設定裡（兩個遊戲共用同一個網址）。
