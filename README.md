# 數學學習扶助

合併自 `math-grade1-forest` 與 `math-grade2-number-sense` 兩個 repo。

- `grade1/` — 一年級數學樂園：數字森林闖關 + 數感快手 + 時鐘操作室 + 數學勇士大挑戰（個人戰／團體戰學習診斷，成績與錯題寫入「診斷測驗紀錄」「診斷作答明細」）
- `grade2/` — 二年級數學學習扶助：小小數學家練習題 + 數感快手特訓 + 時間操作室（鐘面幾點幾分、時間經過、年月日星期，對應 NC-2-13-1、2 與 NC-2-14-1）；成績寫入一年級 `Code.gs` 同一份試算表的「作答紀錄」（關卡ID 為 `timeLab-…`）＋ 數學勇士大挑戰二年級版（32 題、26 個基本學習內容代碼，成績寫入同一份試算表的診斷工作表）
- `shared/` — 數學勇士大挑戰各年級共用的遊戲引擎（`diagnostic.js`：登入、個人戰／團體戰、診斷報告、老師專區）與樣式（`diagnostic.css`）；每個年級的 `diagnostic.html` 只放自己的題庫
- `number-sense-park/` — 數感遊樂園：五種限時挑戰（乘法快手、加減挑戰、拆解特攻、因數獵人、倍數達人），成績經 Google Apps Script（`Code.gs`）寫入試算表排行榜
